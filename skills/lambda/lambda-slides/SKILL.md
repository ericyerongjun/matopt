# LAMBDA analysis slides

Create an editable `slides.pptx` with `python-pptx`. One message per slide. Put every important figure on its own slide.

## Path

1. Gather findings and figures (`figures/`, `lambda_output/`, or call `lambda_data_agent` first).
2. Run the bundled builder (paths are after this skill is loaded):

```bash
python skills/lambda-slides/scripts/make_slides.py \
  --title "Specific data-story title" \
  --subtitle "What the deck argues in one line" \
  --out slides.pptx \
  figures/*.png
```

3. Confirm `slides.pptx` exists (`ls -lh slides.pptx`).
4. Or ask `lambda_data_agent` to build the deck, then copy `lambda_output/*.pptx`.

Do not use Beamer unless the user asked for PDF slides. `python-pptx` is the default.

## Deck order

1. Cover
2. What matters most (3–5 quantified takeaways)
3. Data context (rows, fields, span, limits)
4. Figure-driven insight slides (chart left, key finding right)
5. Segments / comparisons
6. Method only if a model was fit
7. Recommendations
8. Appendix for extra figures

## Style

16:9. Blue header band, light body, white chart panel, white insight card. Three to four bullets per slide, never a wall of text. Match the user's language. Footer may say `Generated by LAMBDA`.

If a chart is unreadable, regenerate it before adding it. Do not dump every figure onto one slide.
