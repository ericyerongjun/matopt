# Demo data and rehearsed examples

`lensing.csv` contains 12 synthetic teaching measurements generated around
`deflection = 2 / impact_parameter`. It is not observational evidence.

The two HTML files were generated by real model calls during the 15 November
2026 Docker rehearsal. The Canvas example includes subsequent model-assisted
repairs to its labels, angle units, state synchronization and animation clock.
The packaged Plotly example also has a small manual layout correction to separate
the title and legend and keep its toolbar hidden after slider changes.
They are fallback examples, not proof that every fresh generation will work.

To show them in MatOpt without another model call:

1. Open a conversation, then **Workspace → Files → Upload files**.
2. Upload `interstellar-cinematic-disk.html` and/or `synthetic-fit-explorer.html`.
3. Select the uploaded file and leave **Preview** selected.
4. Move the controls. Describe this as a **previously generated example**.

The black-hole app is a cinematic illustration, not relativistic ray tracing.
The Plotly app embeds the synthetic data and offers an amplitude slider; moving
it changes the curve, not the underlying observations or an automatically
refitted optimum. Its supported pinned Plotly URL is rewritten to MatOpt's local
bundle inside the preview runtime. Open it in MatOpt to exercise that isolation.
